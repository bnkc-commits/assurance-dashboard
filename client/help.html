Guide d’utilisation

👤 Apporteurs

  • Inscription : Remplissez le formulaire avec votre nom, identifiant (ex. badou123) et mot de passe. Votre compte sera créé en attente de validation.
  • Validation : Un agent ou l’admin doit activer votre compte avant que vous puissiez vous connecter.
  • Connexion : Une fois validé, utilisez votre identifiant et mot de passe pour vous connecter.
  • Envoi de prospects : Après connexion, remplissez le formulaire prospect (nom + demande) et envoyez-le. Les agents recevront vos informations en temps réel.

🧑‍💼 Agents / Admin

  • Connexion : Connectez-vous avec vos identifiants. Le compte initial est admin@admin.admin / admin (à modifier immédiatement).
  • Validation des inscriptions : Utilisez le formulaire de validation pour activer les comptes apporteurs en attente.
  • Logs : Consultez l’historique des actions (inscriptions, prospects envoyés, validations).
  • Messages : Recevez en direct les prospects envoyés par les apporteurs.
  • PDF : Cliquez sur “Imprimer Registre PDF” pour générer un document listant tous les prospects.

⚙️ Déploiement

  • GitHub : Placez tous les fichiers dans un repo public ou privé.
  • Render : Créez une base PostgreSQL et un Web Service connecté à votre repo.
  • Variable d’environnement : Ajoutez DATABASE_URL dans les paramètres Render pour connecter votre backend à la base.
  • Premier login : Utilisez admin@admin.admin / admin puis changez le mot de passe.

📖 Workflow complet

  1. Apporteur s’inscrit → compte en attente.
  2. Admin valide → compte actif.
  3. Apporteur actif se connecte → envoie des prospects.
  4. Agent reçoit les prospects en direct → consulte les logs → génère le PDF.

Ce guide est intégré à l’application pour aider les utilisateurs à comprendre chaque étape.
